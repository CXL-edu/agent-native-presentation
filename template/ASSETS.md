# Asset Contract

Keep all images in `assets/` and record their source or license in `GROUNDING.md`.

- Prefer local PNG, JPG, WebP, or SVG.
- Use `contain` for UI, diagrams, and documents that must remain fully visible.
- Use `cover` only when a deliberate crop is part of the composition.
- Never stretch logos or screenshots.
- Every image needs meaningful alt text; decorative marks use an empty alt.
- Do not use remote HTTP image URLs in an offline deck.
- Use `image-comparison` for before/after or two-state visual comparisons instead of duplicating arbitrary image cards.
