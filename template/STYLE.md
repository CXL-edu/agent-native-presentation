# Style Contract

- Use short, conclusion-driven titles.
- One slide = one primary message.
- Delete or split before shrinking text.
- All numbers and factual claims need GROUNDING evidence.
- Vary composition according to the claim.
- Avoid filler, generic AI language, decorative repetition, and dashboard-like density.
- Code excerpts are short, selectable, copyable, and tied to a slide claim.
- Animated SVG reveals sequence or causality and has a complete print/reduced-motion final state.
