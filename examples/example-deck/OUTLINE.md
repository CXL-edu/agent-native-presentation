# Audience

Technical leaders, design engineers, and Coding Agents that need to produce and maintain visual documents.

# Goal

Show why a reusable HTML/SVG deck system is a better source of truth for agent-driven presentation work than a one-off binary PPTX workflow.

# Core Thesis

A presentation should be a version-controlled, grounded, programmable visual document.

# Story Arc

1. Reframe the editable unit from a file to a system.
2. Make the code-first trade-off explicit.
3. Show the grounded workflow and deterministic stage.
4. Close on the iteration loop and quality heuristic.

# Slide Outline

01. A presentation the agent can keep editing — open with the thesis.
02. The editable unit is the system — explain the shift.
03. Keep PowerPoint at the edge — make the architecture decision visible.
04. The workflow makes each transformation explicit — show the sequence.
05. Research should leave a trace — show handoffs.
06. Start with a small engine — explain MVP layering.
07. Every visual change should be reversible — make QA concrete.
08. Quality compounds — offer a memorable heuristic.
09. Version-controlled. Grounded. Programmable. — close with the thesis.

# Narrative Review

- No slide is required to understand a new concept before it is introduced.
- Slides 02 and 03 are related but non-duplicative: one is the thesis, one is the implementation choice.
- Removing slide 06 would weaken the argument that the system should grow incrementally.
- The close restates the thesis only after the workflow and QA have made it concrete.
